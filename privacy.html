Privacy Policy

Last updated 4 September 2026

This policy covers Saltwater Pipeline, a private automation tool that renders ambient video files and uploads them to the Saltwater YouTube channel.

Who this applies to

Saltwater Pipeline is a single-operator tool. It is used only by the owner of the Saltwater channel, on that owner's own YouTube account. It is not offered to the public, has no sign-up, and has no users other than its operator. If you are reading this because you are deciding whether to grant it access to a Google account, that account is your own and the answer below describes what it would do with it.

What data is accessed

When authorised, the tool uses Google's YouTube Data API to do exactly two things on the connected channel:

  • Upload a video file, together with its title, description and tags.
  • Add an uploaded video to a playlist on the same channel.

It also reads the channel's own name and ID once, to confirm it is connected to the intended channel.

What data is stored

The tool stores, on infrastructure controlled by its operator:

  • An OAuth refresh token for the connected Google account, held as an environment variable so uploads can run on a schedule.
  • Video metadata it generated itself — titles, descriptions, tags, and the IDs of videos it has uploaded — so the same night is never published twice.

Rendered video files are deleted from disk immediately after a successful upload.

What is not done

  • No data is sold, rented, or shared with any third party.
  • No data is used for advertising or profiling.
  • No personal data belonging to viewers of the channel is collected — the tool has no access to viewers and no analytics of its own.
  • Google user data is never used to train any AI or machine-learning model.
  • No data is transferred to anyone other than the Google APIs the tool calls directly.

Google API Services User Data Policy

Saltwater Pipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

The refresh token is kept only while the tool is in use. Access can be withdrawn at any time from the Google account's permissions page, which immediately and permanently ends the tool's access. To have stored metadata deleted, write to the address below.

Third-party services

The tool calls a small number of external services in the course of building a video: stock footage and audio providers, and a transactional email service used to send the operator a status report. None of them receive Google user data.

Changes

Any change to this policy will be published on this page with a new date.
